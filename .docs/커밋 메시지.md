# 예시1

## 변경 사항

### 클라이언트 첨부파일 전송 기능

- ChatMessenger.tsx:
  - fileInputRef, messageListRef 추가로 파일 입력/메시지 리스트 조작
  - uploadAttachmentFiles: 파일 업로드 및 첨부파일 메시지 전송
  - handleAttachmentInputChange: 파일 선택 후 업로드 처리
  - handleComposePaste: 클립보드 붙여넣기로 이미지 업로드
  - renderMessageContent: 첨부파일 렌더링 (이미지 미리보기/파일 링크)
  - normalizeUploadedAttachment: 업로드된 파일 정규화
  - isImageAttachment, isAttachmentExpired: 첨부파일 타입/만료 판단

### 무한 스크롤 메시지 로딩

- ChatMessenger.tsx:
  - loadOlderMessages: 스크롤 업 시 이전 메시지 페이지네이션 로드
  - fetchMessagePage: 메시지 페이지 fetch (beforeMessageIdx 지원)
  - handleMessageListScroll: 상단 임계값 도달 시 이전 메시지 로드
  - hasMoreOlderMessages, isLoadingOlderMessages 상태 추가
  - useLayoutEffect로 스크롤 위치 자동 관리 (preserve/bottom 모드)

### 메시지 렌더링 개선

- ChatMessenger.tsx:
  - formatAttachmentSize: 파일 크기 포매팅 (B/KB/MB/GB)
  - CHAT_ATTACHMENT_EXPIRE_TEXT 상수로 만료 표시
  - renderMessageContent로 TEXT/IMAGE/FILE 구분 렌더링
  - 첨부파일 UI: 이미지 미리보기, 파일 다운로드 링크

### 파일 서버 엔드포인트

- file.controller.ts: /view/:fileIdx 엔드포인트 추가 (inline 스트리밍)
- file.service.ts:
  - streamInline: 브라우저에서 파일 표시 (Content-Disposition: inline)
  - streamDownload: 파일 다운로드 (Content-Disposition: attachment)
  - removeExpiredFiles @Cron: 10분마다 만료된 파일 자동 정리
  - assertFileNotExpired: 만료 파일 검증

### 만료 파일 관리

- app.module.ts: ScheduleModule 추가
- file.service.ts:
  - CHAT_ATTACHMENT_EXPIRE_DAYS = 14 상수
  - isChat 모듈 감지 시 14일 만료 설정
  - Cron으로 10분마다 DB/디스크의 만료 파일 정리

### 백엔드 첨부파일 지원

- chat.gateway.ts:
  - SendChatMessageBody에 messageType, attachment 필드 추가
  - ChatNotificationMessage 타입 확장
  - buildNotificationBody: IMAGE/FILE 메시지 타입별 알림 본문 생성

- chat.service.ts:
  - createMessage: messageType, attachment 파라미터 추가
  - normalizeMessageType: TEXT/IMAGE/FILE 검증
  - normalizeAttachment: 첨부파일 필드 검증 및 정규화
  - parseAttachment: 메시지 content에서 첨부파일 JSON 파싱
  - buildLastMessagePreview: 메시지 타입별 미리보기 텍스트 생성
  - toMessageSummary: IMAGE/FILE 메시지는 content 비우고 attachment 반환

### 타입 및 스타일

- chat.type.ts: ChatAttachment 타입 정의, CHAT_MESSAGE_TYPES 상수
- chat.res-dto.ts: ChatMessageResDto에 attachment 필드 추가
- ChatMessenger.module.scss:
  - .attachmentBlock, .attachmentImage, .attachmentImageLink 등 이미지 UI
  - .fileAttachment, .fileAttachmentIcon, .fileAttachmentInfo 등 파일 UI
  - .composeActions 버튼 레이아웃
  - 모바일 반응형 처리

### 소켓 통신 개선

- chat-socket.ts: sendChatMessage에 messageType, attachment 파라미터 추가

## 효과

- 사용자가 채팅에서 직접 파일/이미지 업로드 및 공유 가능
- 클립보드 붙여넣기로 빠른 이미지 전송
- 이미지는 브라우저에서 미리보기, 파일은 다운로드 링크 제공
- 첨부파일 자동 만료로 저장소 관리
- 메시지 무한 스크롤로 채팅 히스토리 자유로운 탐색
- 스크롤 자동 관리로 자연스러운 UX 제공
